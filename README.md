# SOUL RAIDERS

PC向け見下ろし型アクションRPG。現在はブラウザで動く戦闘プロトタイプを開発中です。

## 起動
GitHub Pages等の静的ホスティングで公開するか、ローカルHTTPサーバー経由で `index.html` を開いてください。

## Prototype 0.3.0
- 新規ゲーム開始時に3ページ構成のオープニングを再生
- スキップ可能、既存データのロード時は再生せず拠点へ移動

## Prototype 0.2.0
- タイトル画面から新規作成・続きからを選択
- 3つのセーブスロット
- プレイヤー名作成（1〜12文字）
- プレイヤー名、所持魂の結晶、プレイ時間をブラウザ内に自動保存
- セーブデータの読み込み

## Prototype 0.1.0
- タイトル画面・拠点・ミッション出動
- 見下ろし型の森フィールド
- WASD / 矢印キー移動、J / 左クリック攻撃、Space回避
- 通常敵6体とボス「森喰い」
- HP・討伐目標・魂の結晶報酬

## 操作
| 操作 | 内容 |
|---|---|
| WASD / 矢印 | 移動 |
| J / 左クリック | 攻撃 |
| Space | 回避 |
| Esc | 拠点へ戻る |

まず操作感と戦闘の基礎を固め、その後に仲間、装備、魂、素材製作、ミッション、協力通信を追加します。
