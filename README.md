# SOUL RAIDERS

PC向けアクションRPG。拠点・任務・4人パーティー・素材収集・装備製作・ボス討伐を軸に、バスターズ型のゲームサイクルを独自世界観で再構築しています。



PC向けアクションRPG。『妖怪ウォッチバスターズ』の拠点・出動・4人パーティー・素材収集・ボス討伐というゲームサイクルを参考に、世界観とキャラクターは独自に開発しています。



PC向け見下ろし型アクションRPG。ブラウザで動作するプレイアブルプロトタイプを開発中です。

## 起動
GitHub Pages等の静的ホスティングで公開するか、ローカルHTTPサーバー経由で `index.html` を開いてください。

## 操作
| 操作 | 内容 |
|---|---|
| WASD / 矢印 | 移動（拠点・ミッション） |
| E | 拠点の施設を調べる |
| J / 左クリック | 攻撃（ミッション） |
| Space | 回避（ミッション） |
| Esc | 施設を閉じる / ミッションから拠点へ帰還 |

※セーブデータは同じブラウザ・同じ端末のローカルストレージに保存されます。
