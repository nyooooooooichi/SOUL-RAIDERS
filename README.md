# SOUL RAIDERS

現在のバージョン：Prototype 0.5.0

PC向け見下ろし型アクションRPG。ブラウザで動作するプレイアブルプロトタイプを開発中です。

## 起動
GitHub Pages等の静的ホスティングで公開するか、ローカルHTTPサーバー経由で `index.html` を開いてください。

## Prototype 0.5.0
- レイダーズ拠点を、キャラクターを自由に歩かせられる見下ろし型マップに変更
- WASD / 矢印キーで拠点内を移動
- ミッション受付、装備工房、仲間管理所、魂の祭壇、アイテムショップを配置
- 施設に近づくと調べる案内を表示し、Eキーで施設メニューを開ける
- ミッション受付からMISSION 001へ出動
- 拠点でのプレイ時間を計測し、セーブデータへ反映

## Prototype 0.4.0
- 拠点画面のプレイヤー情報・所持通貨・プレイ時間表示を整理
- 手動セーブと拠点帰還時の自動セーブを追加
- ※0.5.0で拠点画面を歩行可能なマップへ置き換え

## Prototype 0.3.1
- タイトル画面のボタンが装飾レイヤーに遮られないよう修正
- メニューのクリック領域と重なり順を調整

## Prototype 0.3.0
- 新規ゲーム開始時に3ページ構成のオープニングを再生
- スキップ可能、既存データのロード時は再生せず拠点へ移動

## Prototype 0.2.0
- タイトル画面から新規作成・続きからを選択
- 3つのセーブスロット
- プレイヤー名作成（1〜12文字）
- プレイヤー名、所持魂の結晶、プレイ時間をブラウザ内に自動保存
- セーブデータの読み込み

## Prototype 0.1.0
- タイトル画面・拠点・ミッション出動
- 見下ろし型の森フィールド
- WASD / 矢印キー移動、J / 左クリック攻撃、Space回避
- 通常敵6体とボス「森喰い」
- HP・討伐目標・魂の結晶報酬

## 操作
| 操作 | 内容 |
|---|---|
| WASD / 矢印 | 移動（拠点・ミッション） |
| E | 拠点の施設を調べる |
| J / 左クリック | 攻撃（ミッション） |
| Space | 回避（ミッション） |
| Esc | 施設を閉じる / ミッションから拠点へ帰還 |

※セーブデータは同じブラウザ・同じ端末のローカルストレージに保存されます。
