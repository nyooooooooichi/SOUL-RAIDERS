# SOUL RAIDERS パッチノート

## Prototype 0.1.0
- 初期プロジェクトを作成
- タイトル画面・拠点・ミッション選択を追加
- 見下ろし型の森フィールドを実装
- プレイヤー移動・通常攻撃・回避を実装
- 通常敵6体と大型ボス「森喰い」を追加
- HP表示、討伐目標、魂の結晶報酬を追加

※操作感と戦闘の基礎を確認するための試作品です。
## Prototype 0.2.0
- タイトル画面を「はじめから」「つづきから」に変更
- 3つのセーブスロットを追加
- 新規ゲーム開始時のプレイヤー名入力を追加（1〜12文字）
- プレイヤー名、レベル、魂の結晶、プレイ時間をブラウザ内に保存
- セーブデータの読み込みに対応
- ミッション帰還時・ボス討伐時に自動保存

※セーブデータは同じブラウザ・同じ端末のローカルストレージに保存されます。ブラウザデータ削除や別端末への自動引き継ぎには対応していません。

## Prototype 0.3.0
- 新規ゲーム開始後にプロローグを追加
- 世界観・魂の異変・レイダーの役割を3ページで紹介
- 「次へ」で読み進め、「スキップ」で拠点へ進めるように変更
- 既存セーブデータのロード時はプロローグを再生せず拠点へ移動

## Prototype 0.3.1
- タイトル画面の装飾レイヤーがボタン操作を妨げないよう修正
- メニューとボタンのクリック領域・重なり順を明示
