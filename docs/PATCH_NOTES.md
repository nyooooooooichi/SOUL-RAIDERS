# SOUL RAIDERS パッチノート

## Prototype 0.1.0
- 初期プロジェクトを作成
- タイトル画面・拠点・ミッション選択を追加
- 見下ろし型の森フィールドを実装
- プレイヤー移動・通常攻撃・回避を実装
- 通常敵6体と大型ボス「森喰い」を追加
- HP表示、討伐目標、魂の結晶報酬を追加

## Prototype 0.2.0
- タイトル画面を「はじめから」「つづきから」に変更
- 3つのセーブスロットを追加
- 新規ゲーム開始時のプレイヤー名入力を追加（1〜12文字）
- プレイヤー名、レベル、魂の結晶、プレイ時間をブラウザ内に保存
- セーブデータの読み込みに対応
- ミッション帰還時・ボス討伐時に自動保存

※セーブデータは同じブラウザ・同じ端末のローカルストレージに保存されます。

## Prototype 0.3.0
- 新規ゲーム開始後にプロローグを追加
- 世界観・魂の異変・レイダーの役割を3ページで紹介
- 「次へ」で読み進め、「スキップ」で拠点へ進めるように変更
- 既存セーブデータのロード時はプロローグを再生せず拠点へ移動

## Prototype 0.3.1
- タイトル画面の装飾レイヤーがボタン操作を妨げないよう修正
- メニューとボタンのクリック領域・重なり順を明示

## Prototype 0.4.0
- 拠点のプレイヤー情報、レベル、魂の結晶、プレイ時間表示を整理
- 拠点から手動セーブできる機能を追加
- Escで拠点へ戻る際にもセーブするよう修正

## Prototype 0.5.0
- 拠点を静的なメニュー画面から、自由に歩き回れる見下ろし型マップへ変更
- WASD / 矢印キーによる拠点内移動を実装
- ミッション受付、装備工房、仲間管理所、魂の祭壇、アイテムショップをマップ上に配置
- 施設の近くでインタラクト案内を表示し、Eキーで施設メニューを開けるように変更
- ミッション受付から既存のMISSION 001へ出動できるよう接続
- 拠点内のプレイ時間計測とセーブ表示を追加
