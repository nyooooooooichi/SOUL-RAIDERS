# SOUL RAIDERS パッチノート

## Prototype 1.9.0 - 3D HUB WORLD\n- 3D開発ステージをレイダーズ拠点の3Dプレビューへ刷新\n- 本部・ミッション受付・装備工房・仲間管理所・ショップの5施設を立体建築として配置\n- 中央広場、石畳の大通り、魂のモニュメント、街灯、樹木群、外周装飾を追加\n- 建物・樹木・モニュメントにシャドウを設定し、環境光・フォグで奥行きを表現\n- 三人称カメラを拠点探索向けに調整し、プレイヤーの移動範囲を制限\n- 既存2D本編とセーブデータは維持。3D拠点は独立した移行プロトタイプ\n\n## Prototype 1.8.0 - CHARACTER ANIMATION & MODEL QUALITY
- 3D開発ステージにIdle / Walk / Run / Jumpアニメーションの自動判定・切り替えを追加。該当クリップを含むモデルで再生
- Shiftキーで走行、Spaceキーでジャンプ
- 移動方向へキャラクターが自然に旋回
- GLB / GLTFモデルの中心・接地点・高さを自動調整
- モデル読込時にTriangles数を集計し、画面へ表示
- プレイヤー30,000〜80,000、通常敵10,000〜40,000、ボス60,000〜150,000 trianglesを品質目安として明記
- カメラ追従をdelta timeベースの滑らかな補間へ変更
- モデルに該当アニメーションクリップがない場合は関節アニメーションを捏造せず、移動・ジャンプ操作のみを提供

## Prototype 1.7.0 - 3D FOUNDATION
- タイトル画面に「3D開発ステージ」を追加。既存ゲームとは独立した3D検証環境を起動可能
- Three.js / WebGLによるリアルタイム3Dレンダリングを導入
- 三人称カメラ、WASD・矢印キー移動、マウスドラッグによるカメラ旋回を実装
- 立体地形、木々、建物、環境光・平行光、シャドウを追加
- GLB / GLTFファイルを読み込み、仮プレイヤーを3Dモデルへ置き換え可能
- 既存のCanvas 2Dゲームとセーブデータは維持。3D本編への統合は今後の段階で実施
