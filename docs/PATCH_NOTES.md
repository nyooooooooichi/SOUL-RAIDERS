# SOUL RAIDERS パッチノート

## Prototype 1.4.0
- ミッション中の探索要素を追加：各任務に宝箱1個・素材採取ポイント3か所を配置
- 宝箱を開けると鉄鉱石・霊木・魂晶片・魔獣の核をまとめて獲得
- 採取ポイントでは種類に応じた素材を獲得
- Eキーで近くの探索対象を調べられるように変更
- HUDに最寄りの探索対象までの距離、または操作案内を表示
- 任務ごとに探索物の位置・素材構成を変更
- 探索物は任務出動ごとに再配置され、周回時の素材収集に対応


## Prototype 1.3.0
- ストーリーを「拠点で依頼受注 → ブリーフィング → 出動 → ボス討伐 → 拠点帰還」のミッション型に再構成
- 新規ゲームの導入をレイダーズ本部での新人任務として改訂
- ミッション受付にストーリー進行表示を追加
- 第1話「森の見回り」クリアで第2話「深部の回収作戦」を解放
- 第2話クリアで第3話「古戦場の大型個体討伐」を解放
- 出動前に任務内容・討伐目標・報酬を確認できるブリーフィング画面を追加
- クリア済み任務は繰り返し受注可能
- 初回クリア時に後日談を表示し、次の任務解放を通知
- ストーリー進行状況をセーブデータへ保存。既存データには空の進行情報を自動追加


## Prototype 1.2.0
- 装備システムを8カテゴリへ拡張：武器、うでわ、杖、ゆびわ、盾、おまもり、ベルト、チャーム
- 晶導の長杖、魂脈の指輪、護りの護符、レイダーのベルトを新規追加
- 新装備は装備工房で素材を消費して製作可能
- 仲間管理画面の個別装備欄を8枠へ拡張
- 装備の攻撃・防御・最大HP補正は既存の能力計算に合算
- 既存の装備IDとセーブデータ構造は維持

## Prototype 1.1.0
- 仲間管理画面に仲間ごとの装備設定を追加
- 武器・うでわ・盾・おまもり・魂を仲間ごとに個別装着可能
- 装備・魂の能力値を仲間の攻撃力・防御力・最大HPへ反映
- 仲間の防御力に応じて敵から受けるダメージを軽減
- 装備品・魂の重複装着を防止し、プレイヤーと仲間の装備枠を管理
- 既存セーブデータを壊さず、仲間別装備データを読み込み時に自動補完

## Prototype 0.7.0

## Prototype 0.8.0
- ミッション結果画面を強化し、クリア・失敗のどちらからも「拠点へ帰還」を実行可能に変更
- リザルト画面の重なり順とクリック領域を修正し、帰還ボタンを操作しやすく調整
- CPU仲間の行動を役割別に変更：アタッカーは接近戦、タンクは前線・敵の注意引き、レンジャーは距離を維持、ヒーラーは味方を回復
- CPU仲間ごとに敵との距離・攻撃間隔・立ち位置を個別制御
- 通常攻撃に加えて、プレイヤー用スキル1・スキル2を追加（キー1/2・画面ボタン）
- スキルにクールタイムを追加
- 仲間ごとに固有のスキル候補を2種類ずつ用意し、仲間管理画面から選択可能に変更
- 仲間経験値・レベルをセーブデータに保存し、Lv.3で各スキル枠の2種類目を解放
- ミッションクリア時に経験値を付与し、仲間のレベルとスキル選択を保存
- プレイヤーHPが0になった場合は任務失敗リザルトを表示し、拠点へ帰還可能に変更

## Prototype 1.0.0
- 装備工房を実装し、素材を消費して武器・うでわ・盾・おまもりを製作可能に変更
- 装備を付け替えると攻撃力・防御力・最大HPがミッション中の能力に反映
- 通常敵から鉄鉱石・霊木・魂晶片、低確率で魔獣の核を入手
- ボス撃破時に任務別の素材ボーナスと固有のボス魂を獲得
- 魂の祭壇でボス魂を1つ装着でき、攻撃・防御・最大HPが上昇
- アイテムショップで魂晶12個を消費して回復薬を購入
- Hキーで回復薬を使用し、HPを最大55回復
- セーブデータに素材・装備・魂・回復薬のインベントリを追加
- 既存セーブデータはロード時にインベントリ項目を自動補完
